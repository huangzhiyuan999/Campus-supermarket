# 未来超市

#### Description
模仿美团小象超市实现校园商店速递解决方案，本项目基于开源项目二次开发，采用前后端分离架构，使用 IDEA + Git + Gitee 完成协作开发，模拟真实企业开发流程。本人负责后端服务开发，实现商品浏览、订单管理、数据统计等完整业务功能，集成Java版AI购物助手，基于SpringBoot+大模型API+函数调用，实现聊天式加购、多轮对话等功能，为校内师生提供高效便捷的线上购物体验。
